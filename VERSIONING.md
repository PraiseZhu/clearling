# Versioning

Use semantic versions in package.json and the extension manifest. Keep source
under version control, exclude builds, browser profiles, credentials and private
samples. Commit and publish only with matching authorization. Initial release:
0.1.0. Current release: 0.5.2.

Personal source repository: https://github.com/PraiseZhu/clearling (private).
The main branch contains source, fixtures, tests and build scripts. Packaged
extensions and the signing private key remain outside version control.
